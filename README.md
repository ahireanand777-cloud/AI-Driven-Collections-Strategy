# Delinquency Risk Analytics & AI Collections Strategy

## Project Overview
This project was completed as part of the Tata iQ GenAI Powered Data Analytics Virtual Experience Program.

The project focused on analyzing customer delinquency risk, designing a predictive modeling framework, generating business recommendations, and developing an AI-driven collections strategy to support proactive debt collection decisions.

## Project Stages

### 1. Exploratory Data Analysis (EDA)
- Identified missing values and data inconsistencies
- Performed data cleaning and conditional imputation
- Analyzed key delinquency risk indicators
- Examined customer behavior and repayment patterns

### 2. Predictive Delinquency Modeling
- Selected Logistic Regression for binary risk prediction
- Identified top predictive variables influencing delinquency
- Designed a model evaluation framework using:
  - Accuracy
  - Precision
  - Recall
  - F1-Score
  - AUC-ROC

### 3. Business Recommendation Strategy
- Developed SMART collections recommendations
- Identified high-risk customer segments
- Proposed targeted intervention and outreach strategies

### 4. AI-Driven Collections System
- Designed a high-level AI-powered collections workflow
- Defined autonomous vs. human oversight activities
- Proposed responsible AI and fairness guardrails
- Evaluated expected business and customer impact
